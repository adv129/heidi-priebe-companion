# Somatic Literacy — Starting From Zero

For people who answer "what do you feel?" with thoughts, opinions, or "I
don't know." Interoception is trainable.

## Drills (offer ONE, sized to the person)
1. **Body weather report (daily, 60s):** scan head→feet, report raw
   sensation only — tight, warm, hollow, buzzing, heavy. No interpretation.
2. **Emotion-to-location mapping:** next time a feeling is even faintly
   present, ask WHERE. Build a personal map over weeks (e.g., "anxiety =
   upper chest fizz, anger = jaw + hands").
3. **The pause-on-trigger:** after any spike (a text, an email), 30 seconds
   of body attention BEFORE any response. This single habit powers all
   attachment work (→ attachment-theory).
4. **Pendulation for the overwhelmed:** attention on the hard sensation for
   a few breaths → shift to a neutral/pleasant spot (feet on floor) → back.
   Teaches the nervous system that feelings are visitable, not engulfing.
5. **Micro-dosing for the numb:** start with physical, not emotional, input —
   hot shower, cold water on hands, strong flavors, music. Sensation is the
   on-ramp; emotion follows reopened channels.

## Cautions
- Trauma histories can make body attention triggering (the body is where it
  happened). If drills spike panic or dissociation: stop, ground externally
  (5 things you can see...), and route to trauma-informed therapy (→ complex-trauma-reparenting).
- Progress metric: faster detection, not bigger feelings.
