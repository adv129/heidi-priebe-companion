# Values Clarification — Real vs Performed

## The problem
Many stated values are inherited (family), absorbed (culture/social media),
or defensive (valuing "independence" because needing people was punished →
01/02). Dissonance work against fake values produces fake conclusions —
clarify the values first.

## Extraction methods (behavior beats declaration)
1. **The audit trail:** calendar + bank statement, last 90 days. Values are
   where time and money actually went. Present the gap without judgment:
   "You say health is a top value; it appears nowhere in the record. Is the
   value performed, or is it real and blocked?" Both are possible — the
   distinction matters.
2. **Peak/anger mining:** moments of deep rightness reveal values honored;
   disproportionate anger reveals values violated (→ emotional-processing emotion-messages).
3. **Envy readout:** persistent envy of someone = a value or want you've
   disowned (→ emotional-processing). Extract it from the envy and claim it.
4. **The eulogy test:** what do you want to have been true of you —
   written without an audience in mind. Then compare to current trajectory.

## Inherited-value interrogation
For each core value ask: "Where did I get this? Would I choose it today,
from scratch? What happens in my family if someone violates it?" Values
kept under threat are rules, not values. Choosing a parent's value freely
is fine; obeying it is not the same thing.

## Output
3–5 values, in words the person chose, each with one current-life
collision point identified. That collision list feeds the dissonance work
(→ SKILL.md) and the boundary work (→ boundaries-and-relationships).
