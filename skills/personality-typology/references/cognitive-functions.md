# The Eight Cognitive Functions — Healthy vs Unhealthy

| Fn | Healthy expression | Unhealthy / overused |
|---|---|---|
| **Se** | Present, embodied, responsive, sensory joy | Impulsivity, sensation-chasing, escapism via stimulation |
| **Si** | Reliable, detailed memory, tradition as comfort, routines that serve | Rigidity, catastrophizing from past data, "we've always done it this way" |
| **Ne** | Generative, connective, sees possibilities everywhere | Scattered, commitment-phobic, anxiety of infinite what-ifs |
| **Ni** | Pattern-convergence, long-range vision, symbolic insight | Tunnel certainty, paranoia-flavored predictions, dismissing present data |
| **Te** | Organizes, decides, executes, measures | Steamrolling, efficiency over people, workaholism as regulation |
| **Ti** | Precise internal logic, framework-building, intellectual honesty | Analysis paralysis, cold dismissal, correcting over connecting |
| **Fe** | Attunes, harmonizes, cares for the room | Self-erasure for harmony (→ self-abandonment), emotional management of others (→ boundaries-and-relationships) |
| **Fi** | Values-anchored, authentic, morally courageous | Self-absorption, judgment via private moral code, wounded withdrawal |

## Use note
When a person describes a struggle, locate WHICH function is over/under-
working before locating which type they are. Function language stays useful
even when typing is uncertain.
